Athar (أثر) documentation
=========================

Athar is a Flutter app that helps people cut their screen time and build
healthier habits. It tracks scrolling, screen time, social media, gym and
phone-free hours, builds a personal plan, and gives AI coaching.

This documentation explains what the app includes, how it's built, how each
feature was specified and planned with **Spec Kit**, where those specs appear
in the code, and how the **Superpowers** plugin supported the work.
